## Working preferences
- When the user provides an image and asks to use it, use the actual image file as-is (save it into `public/` and reference it). Do NOT recreate it as an SVG, redraw it, or substitute an approximation.
- Never use em dashes (—) in copy. Rewrite sentences naturally without them.
- Never end section titles (h1, h2, h3) with a full stop.
